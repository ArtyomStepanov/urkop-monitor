# Monitor

Браузерная разморозка турнирной таблицы Тимуса в классическом стиле Monitor. Работает как статический сайт на GitHub Pages.

В репозитории только приложение и вымышленные демонстрационные данные. Настоящие CSV с участниками/тренерами и логи пользователь выбирает на своём компьютере; они разбираются в браузере.

## Возможности

- Заморозка последних N минут и выбор диапазона мест.
- Пошаговое раскрытие, автопоказ, скорость, стрелки и режим только таблицы.
- Составы команд: три участника и тренер; импорт CSV и ZIP логов Тимуса.
- Дипломы по диапазонам мест, проход, wild card и карточки награждения.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root) → Save. Файл .nojekyll включает публикацию статических файлов без Jekyll.
