Monitor — управление

Браузерный монитор по приложению из папки freeze. Сохранены цвета, порядок столбцов и компактная таблица исходного приложения.

  1. Выберите пример или загрузите ZIP с full.log и teams.txt. Эти два файла можно выбрать вместе без архива.
  2. Укажите длительность олимпиады и сколько последних минут скрывать. Например: 300 минут, скрывать последние 60 — результаты начиная с 240-й минуты будут скрыты.
  3. Укажите диапазон мест и нажмите «Применить». Выбираются команды по замороженной таблице; при равном месте включаются все команды с этим местом.
  4. Стрелка → работает в два нажатия: первое только выделяет команду и её скрытую задачу, второе раскрывает результат. Следующее нажатие выбирает следующую задачу. Стрелка ← возвращает эти действия по порядку. «Старт» автоматически чередует выделение и раскрытие, выдерживая паузу между ними. Команды вне диапазона сохраняют заморозку.

В синей ячейке показано число попыток, включая попытки до заморозки, но их скрытые вердикты не раскрываются. После раскрытия цвет становится насыщеннее. В столбце = число в скобках — сколько задач было решено до заморозки.

Автоматическое награждение показывает один диплом без кнопок. → или Esc закрывает карточку и возвращает к таблице. В ручном награждении кнопка «Для фото» скрывает панели, стрелки листают карточки, Esc возвращает к таблице.
